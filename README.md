# Homebrew Tap for Glincker Tools

```bash
brew tap glincker/tap
```

## Tools

| Tool | Install | What it is |
| --- | --- | --- |
| [stacklit](https://github.com/glincker/stacklit) | `brew install glincker/tap/stacklit` | Token-efficient codebase index for AI coding agents. Open source (MIT). |
| [sslx](https://github.com/glincker/sslx) | `brew install glincker/tap/sslx` | The modern way to work with certificates and TLS. |
| [levelrail-cli](https://levelrail.com) | `brew install glincker/tap/levelrail-cli` | Command line client for Levelrail, a self-hosted deployment platform. |

## Quick start: stacklit

```bash
brew install glincker/tap/stacklit
cd your-repo
stacklit init
```

## Update

```bash
brew update
brew upgrade glincker/tap/stacklit
```

Formulas are updated from each project's release pipeline.
